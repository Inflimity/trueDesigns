HOW TO ADD IMAGES
=================

Product/Portfolio images are now loaded from these folders.
Please add your images to the respective folder and name them as follows:

1. Logo Design
   Folder: assets/images/logo/
   Files: 1.png, 2.png, 3.png ... up to 10.png
   (You can also use 'logo1.png', 'logo2.webp' as we saved those for you)

2. Digital Ads
   Folder: assets/images/ads/
   Files: 1.png, 2.png, 3.png ...

3. Merchandise
   Folder: assets/images/merch/
   Files: 1.png, 2.png, 3.png ...

4. Graphic Design
   Folder: assets/images/graphic/
   Files: 1.png, 2.png, 3.png ...

5. Web Design
   Folder: assets/images/web/
   Files: 1.png, 2.png, 3.png ...

6. E-Commerce
   Folder: assets/images/ecom/
   Files: 1.png, 2.png, 3.png ...

NOTE:
- Supported formats are generally .png or .jpg, but the code specifically looks for the names listed in index.html.
- Currently configured to look for '1.png', '2.png', '3.png', '4.png', '5.png'.
- If you want to add more, you can edit the list in index.html.
